Перевіряю стан…

Кнопка входу відкриє офіційну авторизацію Anthropic у браузері. Обери робочий Team-акаунт. Після входу ліміти перевіряться одразу. Цей вхід також змінює акаунт у Claude Code CLI. Вхід у Claude Desktop може бути окремим. Помічник не оновлює токен: коли він прострочиться, авторизацію має оновити Claude Code або кнопка входу. Автоматично: раз на 5 хвилин; при простроченому вході — раз на 30 хвилин. Запит лише читає залишок.
